# Geographic exclusions

`location-countries.json` is generated by `node scripts/generate-location-countries.mjs`
from the pinned `cities.json@1.1.65` development dependency, derived from
[GeoNames](https://www.geonames.org/) via [cities.json](https://github.com/lutangar/cities.json).
The source data and this derived index are licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The transformation retains city names and ISO country codes, folds accents,
deduplicates homonyms, and adds English/French/Italian country names.

This is not a complete geocoder. A name shared by several places means the
well-known one (Paris is France, not Texas): `location-exclusions.ts` lists
those, with their French and Italian names. Other shared names, and locations
the index does not know, are withheld when a country is left out; a country
written in the location ("Paris, US") settles it. Leaving out a city only
removes people known to be there. No user location is sent to an external
geocoding service. The index is bundled only into the Edge Function.
